# 마스터 CMS와 공개 대시보드

2026-11-04 사용자 요청으로 추가한 단일 사이트 운영 기능입니다. 일반 제작 도구는 기존처럼 회원가입 없이 사용합니다. 별도 회원가입·여러 운영 계정·다중 사이트 관리는 포함하지 않습니다.

## 처음 시작

1. 저장소 루트의 터미널에서 `npm.cmd --prefix backend run admin:setup`을 실행합니다.
2. 입력이 숨겨진 프롬프트에서 12~128자의 비밀번호를 두 번 입력합니다. 아이디는 **master**입니다. 기본 비밀번호는 없으며 채팅이나 저장소에 비밀번호를 남기지 않습니다.
3. 백엔드를 실행하고 `http://localhost:5173/admin`에서 로그인합니다.
4. 제작 홈에서 만든 시안을 ‘현재 브라우저의 시안 가져오기’로 선택하고 서버 초안으로 복사합니다. 해당 시안이 저장된 브라우저·동일 사이트 주소로 접속해야 목록에 보입니다.
5. ‘초안 편집’에서 기존 CMS를 사용하고 각 속성의 ‘변경 적용’을 누른 뒤 **서버 초안 저장**을 누릅니다. 공개 화면은 아직 바뀌지 않습니다.
6. 관리 화면의 ‘저장본 미리보기’로 확인한 뒤 **저장본 게시**를 누릅니다. 공개 주소는 `http://localhost:5173/dashboard`입니다.

비밀번호 변경/분실 시 서버 터미널에서 `npm.cmd --prefix backend run admin:setup -- --reset`을 실행합니다. 기존 로그인 세션은 모두 해제하며 초안·게시본은 유지합니다. 실제 서버에서는 서비스 계정으로 실행하고 같은 `CMS_DB` 환경값을 사용해야 합니다.

## 저장과 복원

- 서버 SQLite `CMS_DB`(기본 `backend/data/cms.sqlite`)에 마스터 비밀번호의 salt/scrypt 해시, 세션, 로그인 제한 기록, 초안·게시본·이전 게시본 1개를 보관합니다.
- 서버 초안 저장은 명시적 작업입니다. 관리자 편집 중인 미저장 내용은 브라우저에 자동 저장하지 않으며 나가기·새로고침 때 변경 손실을 안내합니다. 일반 제작 프로젝트의 브라우저 자동 저장은 유지합니다.
- 이미지도 번들로 서버에 저장해 다른 기기에서 편집·조회할 수 있습니다. PNG/JPEG/WebP 파일당 2MB, 현재 이미지와 제작 조건에서 참조하는 이미지 최대 2개입니다. SVG·임의 파일은 받지 않습니다.
- 이전 게시본 복원은 현재 공개 화면과 이전 게시본을 교환합니다. 초안은 유지하며 다음 게시 때 다시 덮어쓸 수 있습니다.
- 저장·게시·복원은 서버 revision을 비교합니다. 다른 탭에서 먼저 변경했다면 409로 거부하며 현재 서버 내용을 덮어쓰지 않습니다. 편집 내용은 필요하면 ZIP으로 보관하고 관리 화면에서 서버 내용을 새로고침하세요.
- 공개 API는 게시본만 반환하고 제작 요청(`settings.selections`)과 사용하지 않는 이미지는 제외합니다. 게시한 화면·샘플 데이터는 방문자가 읽을 수 있으므로 공개할 데이터만 게시합니다.
- 브라우저 작업 삭제나 사이트 데이터 삭제가 서버 초안·게시본을 지우지는 않습니다. 서버 데이터 삭제·백업 보관 절차는 운영자가 별도로 관리합니다. 다운로드 ZIP은 정적 결과물이며 이 CMS 서버나 인증 기능이 포함되지 않습니다.

## 인증

### 마스터 AI 테스트 한도

마스터로 로그인한 같은 사이트·브라우저에서는 AI 생성·수정의 개인 및 IP 일일 한도를 면제합니다. 일반 사용자의 생성 3회·수정 10회, AI 상담 한도, 분당 요청·동시 실행·점검 제한은 유지합니다. 면제 호출은 일반 사용량을 차감하지 않으며 기존 사용 기록도 초기화하지 않습니다. 실제 AI 호출 비용은 발생합니다.

기존 로그인 상태라면 `/admin`을 다시 열어 새로고침한 뒤 만들기 화면으로 이동하세요. 기존 CMS 전용 쿠키를 API 전체 경로 쿠키로 전환하며 서버의 원래 8시간 만료 시각은 연장하지 않습니다. 생성·수정 화면에 **마스터 로그인 · 일일 횟수 제한 없음**이 표시되는지 확인하세요. 표시되지 않으면 로그아웃 후 다시 로그인하고 사용량을 새로고침하세요. 로그인한 사이트 주소와 만들기 화면 주소가 같아야 합니다. 로그아웃·만료·비밀번호 재설정 후에는 일반 한도가 적용됩니다.

마스터 계정 1개, 8시간 서버 세션, HttpOnly·SameSite=Strict 쿠키를 사용합니다. HTTPS 운영 origin이면 Secure 쿠키를 발급합니다. 비밀번호는 scrypt 해시, 세션 토큰은 SHA-256 해시로 DB에 보관합니다. 로그인 실패는 IP 해시별 15분 동안 5회까지 허용하며 만료 레코드는 다음 로그인 시 정리합니다. 이 기록은 원본 IP를 저장하지 않지만 익명·무개인정보를 보장한다는 의미는 아닙니다.

모든 관리자 변경 API는 서버 세션·허용 Origin·CSRF 토큰을 확인합니다. 마스터 초기 설정은 공개 HTTP API로 제공하지 않습니다. 일반 제작 페이지는 공개 제작 도구이며 관리자 `/admin`과 구분합니다. `/dashboard`는 읽기 전용입니다.

## 배포 및 검수 범위

호스팅·도메인·외부 배포는 아직 제외 상태입니다. 향후 운영 시 `CMS_DB`를 릴리스 밖 별도 절대 경로로 지정하고 서비스 계정만 접근하도록 합니다. CMS DB와 저널도 보호된 백업·복원 대상에 포함합니다. `/admin`, `/dashboard`는 SPA 경로이므로 정적 서버의 index.html fallback이 필요합니다. Nginx 예시는 최대 6MB 요청 크기를 사용하며 AI 요청은 기존 앱 제한을 별도로 유지합니다.

검증: 인증 실패 제한·만료·비밀번호 변경 후 세션 폐기, 비인증/Origin/CSRF 차단, 초안 비공개, 충돌 거부, DB 재열기 후 이미지·게시본 유지, 이전 게시본 복원. Chrome·Edge에서 격리 계정과 DB로 로그인·시안 가져오기·CMS 편집·저장·미리보기·게시·복원·로그아웃·익명 공개 조회를 확인했습니다. 실계정은 운영자가 위 초기 설정 명령으로 생성해야 합니다.
