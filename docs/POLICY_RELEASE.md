# 이용 안내·정책 공개 준비

작성일: 2026-10-31. 현재 상태: **화면 구현 완료, 약관·개인정보처리방침은 공개 전 검토본**.
검토본은 동의 수집이나 법적 준수 완료의 근거가 아니다. 외부 공개 배포는 수행하지 않았다.

## 화면과 수정 위치

- `#info/service`: 서비스 안내. 제작 범위, AI 입력, 로컬 저장·삭제, ZIP 이용 및 오픈소스 고지.
- `#info/terms`: 이용약관 검토본. 목적·범위·금지 행위·결과물·저장·변경/중단·운영자 확인 사항.
- `#info/privacy`: 개인정보처리방침 검토본. 처리 항목·목적·위치·보관 동작·외부 AI·쿠키·삭제·권리 행사 확인 사항.
- 본문: `sebitcanvers_v3/frontend/src/InfoPage.tsx`, 경로: `infoRoutes.ts`, Footer: `App.tsx`.
- 라이선스 원문: `thirdPartyNotices.ts`. 설치된 Lucide(ISC 및 Feather MIT), React(MIT), JSZip(MIT 선택)의 LICENSE에서 복사했다. 라이브러리 업데이트 때 원문도 검토한다.
- `dashboard/export.tsx`에서 ZIP의 `THIRD_PARTY_NOTICES.txt`와 이용 조건 설명을 제공한다. 상업 이용 조건 확정 시 페이지와 ZIP README를 함께 수정한다.

## 현재 코드와 대조한 사실

| 대상 | 구현 근거 | 안내할 사실 |
|---|---|---|
| 생성 요청 | `backend/src/generate.ts` | 제작 조건·추가 요청·샘플 Schema를 OpenAI API로 전달 |
| 수정 요청 | `backend/src/edit.ts` | 현재 Schema 전체와 수정 요청을 전달. 선택 컴포넌트 수정이어도 전체 Schema가 요청에 포함됨 |
| 이미지 | `create/assets.ts`, `generate.ts` | Blob은 브라우저 IndexedDB. AI 요청에는 참조값만 전송 |
| 프로젝트 | `dashboard/storage.ts`, `deleteProject.ts` | Local Storage. 삭제 시 현재/최초/백업/복구 원문 제거, 삭제 표시 잔존. 이미지 정리는 별도 |
| 식별 쿠키 | `backend/src/usage.ts` | `sebit_ai`, HttpOnly, SameSite=Lax, API 경로, 발급 시 1년. 회원 계정 없음 |
| 사용량 | `usage.ts` | 서버에서 원본 IP를 제한 판단에 사용. DB에는 식별자/IP의 HMAC 변환값과 요청 상태 저장. 7일 전 날짜보다 오래된 레코드를 다음 요청 접수 시 삭제 |
| 진단 기록 | `telemetry.ts` | 요청 ID·종류·시간·상태·오류·처리 시간·토큰 수. 입력/출력 원문은 기록하지 않음. 30일 초과 레코드를 다음 기록 시 삭제 |
| AI 보관 설정 | `generate.ts` | Responses 요청에 `store:false`. 제공업체의 악용 방지 기록·캐시·계정별 보관까지 없다는 뜻은 아님 |
| 서버 환경 | `docs/deployment/` | Nginx/호스팅 접근 로그와 백업은 실제 환경 확인 전. ‘서버 어디에도 IP나 원문을 남기지 않는다’는 포괄 문구를 사용하지 않음 |

기간 경과만으로 즉시 삭제되는 스케줄러는 없으므로 ‘정확히 7일/30일 후 자동 파기’로 표현하지 않는다. 공개 운영에서 고정 보관 기한을 확정한다면 별도 정리 작업·접속 로그·백업 정책도 함께 맞춰야 한다.
