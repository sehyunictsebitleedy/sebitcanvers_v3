총 생성 4건·수정 3건이 통과했습니다. 두 명령 모두 exit 0으로 종료했습니다. 복합 수정과 차트 수정은 기대 Schema 전체와 비교해 비대상 데이터 보존도 확인했습니다. 기존 생성 스크립트는 소요 시간과 토큰을 출력하지 않으므로 해당 수치를 추정하지 않습니다.

실제 호출 비용은 발생할 수 있습니다. 공급자 직접 호출 검사이므로 API 서버의 사용량·진단 DB에는 기록되지 않으며 `report:ai`로 이번 호출을 집계할 수 없습니다. 운영 계정 청구액이나 전체 UI 응답 시간의 검증을 뜻하지 않습니다.

## 브라우저 회귀 검수

프론트엔드 디렉터리에서 다음 명령으로 **10개 통과**, exit 0을 확인했습니다.

```powershell
npm.cmd run test:e2e -- e2e/ai-edit-wait.spec.ts e2e/generationWait.spec.ts e2e/builder.spec.ts
```

- 생성·수정 대기, 취소, 늦은 응답 무시, 시간 초과·네트워크·잘못된 응답 구분.
- 실패 시 제작 조건·기존 저장 데이터 보존, 재시도.
- 4개 유형 선택, 샘플 CMS 편집, 이미지·누락 이미지 처리, 확정·ZIP 다운로드·파일 직접 실행.

이 브라우저 검수는 모의 API를 사용합니다. 실제 AI로 생성한 4개 결과 각각의 화면 품질·ZIP을 브라우저에서 검수한 것은 아닙니다. 실제 공급자 검수와 모의 UI 검수를 구분합니다.
